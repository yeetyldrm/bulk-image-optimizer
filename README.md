\# 🚀 Bulk Image Optimizer (Toplu Görsel Optimize Edici)



A lightweight and fast Python script to bulk optimize images, resize them, and convert them to the modern WebP format.



\## 🌟 Features

\- Converts `.png`, `.jpg`, `.jpeg`, and `.bmp` files to `.webp` automatically.

\- Resizes images proportionally if they exceed a specific width (Default: 1920px).

\- Reduces file size significantly without losing visible quality.
